## Method

Each environment ran one warm-up followed by 30 measured process launches. A
monotonic clock covered process launch through parsed JSON output. Each fixture
was copied to a temporary Git repository, committed, and given one source-only
comment diff. `plan --diff` did not run repository tests. The macOS host was on
AC power. The Linux container used the same arm64 host and
`node:22.13.0-bookworm@sha256:fa54405993eaa6bab6b6e460f5f3e945a2e2f07942ba31c0e297a7d9c2041f62`.
